# Demoday Cardiohub

A mobile app for post-operative cardiac rehabilitation at home.


## Pitch
A hybrid, connected solution to support patients after cardiac hospitalization, facilitating remote medical monitoring.


## Professional Relevance
This project was conceived by a **cardiologist**.
It represents a **first step into the professional world** of web and mobile development, encompassing client relationship management, needs analysis, and the implementation of a practical solution.


## Problem Addressed
Cardiac rehabilitation after hospitalization is still too inaccessible due to:
- a lack of hospital beds,
- long waiting times,
- and the geographical distance between patients and healthcare facilities.


## Proposed Solution
Develop a **mobile application** for hybrid, connected monitoring:
- 🔐 Secure login & authentication
- 📅 Scheduling and conducting video consultations
- 📊 Real-time ECG monitoring via Bluetooth sensor
- ⚖️ Withings integration (weight, blood pressure, health data)
- 💬 Secure messaging & phone calls


## Target Users
- Patients after cardiac surgery (post-hospitalization)
- Prescribing and referring cardiologists
- Other healthcare professionals (nurses, dietitians, etc.)


## Main Features (MVP)
- **Secure authentication**: personal account with protected access
- **Video consultation**: integrated video chat + reminders + history
- **ECG monitoring**: data transmission

## Future Features
- **ECG monitoring**: real-time data transmission during video call
- **Withings integration**: display of weight/blood pressure on a dashboard
- **Messaging & calls**: recorded and integrated into the patient's medical record
